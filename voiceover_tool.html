How it works — all in-browser, no server needed

Everything runs inside your browser — no downloads, no CORS issues, no server headers required:

  • 1Parse markers — Transcript split at every [screenshot:N] tag into segments.
  • 2TTS timing — SpeechSynthesis speaks each segment silently (volume 0). Exact duration measured on onend.
  • 3Record audio — SpeechSynthesis speaks again at full volume while tab audio is captured via getDisplayMedia(preferCurrentTab:true) + ScriptProcessorNode → PCM → WAV file. Requires Chrome 109+. Gracefully skipped if unavailable.
  • 4Encode frames — Screenshot drawn to canvas, sampled as ImageBitmap frames at 10 fps using WebCodecs VideoEncoder (H.264).
  • 5Mux MP4 — Pure-JS ISO BMFF muxer writes a real MP4 container with correct duration — fully seekable.
  • 6Download — MP4 (video, timed to voiceover length) and WAV (audio) are both offered as downloads. Merge them with any free video editor.

Output: MP4 (H.264 silent video, timed to speech) + WAV (voiceover audio). Works on GitHub Pages with no special HTTP headers — pure static HTML.

Missing imageIf you reference [screenshot:5] but only uploaded 3 images, generation fails with a clear error
Other brackets[pause], [note: ...] etc. are stripped from narration timing
Browser: Use Chrome 94+ or Edge 94+ (desktop) — requires WebCodecs API (VideoEncoder).
