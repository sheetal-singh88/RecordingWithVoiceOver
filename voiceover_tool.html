How it works — all in-browser, no server needed

Everything runs inside your browser — no installation required:

  • 1Parse markers — Transcript split at every [screenshot:N] tag into segments.
  • 2TTS per segment — Browser's SpeechSynthesis API speaks each segment silently into an AudioContext; audio is captured as a WAV blob.
  • 3Screenshot → video — FFmpeg.wasm converts each screenshot image into a silent video clip of exactly the right duration.
  • 4Mux — FFmpeg.wasm combines the video clip with its WAV audio into one MP4 segment.
  • 5Concatenate — All MP4 segments are joined in order into the final downloadable MP4.

Output: MP4 (H.264 + AAC). Plays in every browser, phone, and video player. First run downloads ~31 MB of FFmpeg.wasm — subsequent runs use the browser cache.

Marker rules & tips
RuleDetail
Syntax[screenshot:N] where N is 1-based (matches upload order)
PlacementStart of paragraph, inline mid-sentence, or on its own line
ReuseReference the same screenshot multiple times
No markersAll text is narrated over screenshot 1
Missing imageIf you reference [screenshot:5] but only uploaded 3 images, generation fails with a clear error
Other brackets[pause], [note: ...] etc. are stripped from audio
Browser: Use Chrome or Edge (desktop). FFmpeg.wasm requires SharedArrayBuffer which is available on these browsers. The first run downloads ~31 MB of WebAssembly — subsequent runs are instant (cached). Generation is silent — the browser does not play audio out loud while processing.
