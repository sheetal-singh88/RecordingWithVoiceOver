How it works — all in-browser, no server needed

Everything runs inside your browser using standard Web APIs — no installation required:

  • 1Parse markers — Transcript is split at every [screenshot:N] tag into narration segments.
  • 2Load images — Each screenshot is decoded into an HTMLImageElement for canvas drawing.
  • 3Record canvas stream — MediaRecorder captures a canvas.captureStream() as video.
  • 4Speak + record per segment — The browser's SpeechSynthesis API speaks each segment's text while the matching screenshot is drawn on canvas. Recording stops when speech ends.
  • 5Assemble video — All recorded chunks are merged into a single Blob and offered as a WebM download.

Output format: WebM (VP8/VP9 + Opus). Plays in Chrome, Edge, Firefox, and VLC. To convert to MP4 for wider compatibility, drop the file into cloudconvert.com.

Marker rules & tips
RuleDetail
Syntax[screenshot:N] where N is 1-based (matches upload order)
PlacementStart of paragraph, inline mid-sentence, or on its own line
ReuseReference the same screenshot multiple times — it stays on screen for the combined duration
No markersIf there are no markers, all text is narrated over screenshot 1
Missing imageIf you reference [screenshot:5] but only uploaded 3 images, generation fails with a clear error
Other brackets[pause], [note: ...] etc. are stripped from audio but do not affect screenshot switching
Browser requirements: Use Chrome or Edge for best results — they support both SpeechSynthesis and MediaRecorder with canvas streams. Firefox works but may have fewer built-in voices. Safari is not supported (no canvas.captureStream()).
