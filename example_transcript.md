Welcome to the Test Generation demo. In this video we will walk
through the variable reuse feature step by step.

[screenshot:2]
First, open the project and navigate to the Test Generation panel
on the left sidebar. You will see all your existing test suites listed here.

[screenshot:3]
Click Generate Tests. The tool analyses your existing variables
and suggests reuse opportunities automatically.

[screenshot:4]
Notice the variable selector that appears. It shows all variables
already defined in this feature file, so you can reuse them without
re-typing or creating duplicates.

[screenshot:5]
Select the variable from the dropdown and confirm. The test step is
updated immediately, referencing the shared variable.
This ensures consistency across your entire test suite.
